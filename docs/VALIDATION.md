# 1.0.0 验证记录

以下为本地 Windows 验证，不代表 GitHub CI 或 macOS/Linux 的执行结果。

## 已完成

- Ruff 静态检查与格式检查通过。
- 30 项自动化测试通过，包含真实 Tk 窗口生命周期和真实 FFmpeg 图片、音频合成测试。
- 图文短链实测成功，保存图片和配乐，并生成约 50.6 秒的 H.264/AAC MP4。
- 对比网页展示图片与平台下载图片，确认后者的导出模板添加了抖音号水印。
- 修复后图片与已检查的网页无平台水印源文件逐字节一致，重新生成的 MP4 首帧也已检查。
- 独立 exe 实测约 2 秒内显示窗口，完成图文下载、FFmpeg 首次下载及 MP4 合成，关闭后退出码为 0。
- 独立 exe 的无效链接错误提示在 5 秒后仍保持可见，关闭后退出码为 1。
- 构建包版本资源为 1.0.0，作者为 dxy，Tcl/Tk 运行时完整。
- 发布包不包含 FFmpeg 编码器二进制；源码包不包含本地指导文件、Cookie、日志、备份、虚拟环境或下载素材。

## 测试范围

自动化测试覆盖分享文案及多种链接格式、目标 ID 匹配、React Flight 和 RENDER_DATA、
无码率列表的视频地址、画质排序、水印候选和重定向拦截、旧缓存失效、缓存哈希、
下载中断、未知文件大小、取消与子进程回收、不同图片尺寸及完整音轨合成。

水印验证针对实测素材和已识别的地址模板，不是对所有平台作品的视觉检测保证。
源码跨平台校验及远端发布结果以 GitHub Actions 的实际记录为准。

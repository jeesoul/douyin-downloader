# 抖音素材下载小工具 1.0.0

作者：dxy。项目代码使用 MIT 许可证。

支持抖音视频、图文、分享文案和短链接；图文可分别保存无平台水印图片、可获取的配乐，
并合成带音乐的 H.264/AAC MP4。窗口持续显示解析、下载和导出状态，失败可见并可重试。

Windows 用户下载 `douyin-downloader-1.0.0-windows-x64.zip`，解压后运行 `DouyinDownloader.exe`。
无需安装 Python；首次使用联网下载 Chromium，首次图文导出另下载 FFmpeg。
源码包为 `douyin-downloader-1.0.0-source.zip`，文件校验值见 `SHA256SUMS`。

已识别的带水印地址不会作为候选或兜底。图文 MP4 为图片轮播，无法获取配乐时会明确提示警告。
平台验证、内容删除或访问限制可能导致失败。作者已嵌入画面的标识无法仅靠地址识别。
